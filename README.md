# SPX 0DTE 네이키드 매수 전략 — 백테스트

S&P500 지수(SPX) **당일 만기(0DTE) 옵션을 매수만** 하는 단순 규칙을, 옵션 1분·초 단위 호가로 한 거래씩 재현해 검증한 연구 코드입니다.

![누적 손익](figures/equity.png)

| 매매 수 | 총손익 (1계약) | 연평균 | 최대낙폭 | 승률 |
|---|---|---|---|---|
| 395건 | +$78.0k ~ +$79.5k | +$18.0k ~ +$18.3k | −$17.6k ~ −$19.7k | 41% |

기간 2022-05-16 ~ 2026-09-24. 범위는 체결 지연 5초 ~ 10초. NH선물 수수료(계약당 $5)와 나스닥 선물 시세 이용료(CME, 월 $228.80)를 모두 뺀 값입니다.
전체 분석 보고서: [`docs/SPX0DTE_naked_call_backtest.pdf`](docs/SPX0DTE_naked_call_backtest.pdf)

## 매매 규칙

| | |
|---|---|
| 판단 | 뉴욕 10:00:00 |
| 조건 1 | SPX 10:00:00 가격 > 09:31:00 가격 |
| 조건 2 | 나스닥100 마이크로 선물(MNQ) 5분봉(09:55~10:00) 종가 > 일목균형표 구름 윗선 (9·26·52) |
| 매수 | SPX 0DTE 등가격(ATM) 콜 1계약, 매도호가. 미체결 시 매초 매도호가로 재주문 |
| 청산 | 호가 중간값이 매수가 대비 −90%면 손절, 아니면 16:00 SPX 종가로 현금정산 |
| 기타 | 하루 1번, 장중 추가 매수 없음 |

## 결과

**체결 가정별 총손익** (394건, 2026-09-23까지)

| 매수 가격 | −90% 손절 | 손절 없음 |
|---|---|---|
| 10:00:00 매도호가 (지연 없음) | +$84.9k | +$78.2k |
| 5초 뒤 매도호가 | +$77.3k | +$70.4k |
| 10초 뒤 매도호가 | +$78.8k | +$75.7k |

- 10:00:00 직후 1~5초 동안 매도호가가 평균 1~2% 올랐다가 10초 무렵 돌아옵니다(10시 경제지표 발표, 특히 ISM 서비스업). 그래서 10초 지연이 5초보다 조금 낫습니다.
- −90% 손절은 모든 지연 조건에서 만기 보유보다 나았습니다(0으로 끝날 콜의 남은 가치 회수).
- 초 단위 호가는 2023-03-28부터 있습니다. 그 전 75건은 지연 없이 10:00:00 매도호가로 계산했습니다.

**연도별** (10초 지연)

| 2022 (5월~) | 2023 | 2024 | 2025 | 2026 (9/24까지) |
|---|---|---|---|---|
| +$11.2k | +$14.4k | −$1.1k | +$31.6k | +$23.4k |

**2025-04-09 (관세 유예 발표일)** — 한 건 +$36,530(매수 금액 대비 +511%)으로 전체 이익의 약 40%입니다. 이익이 10시 판단과 무관한 13:18 발표에서 나와, 이날을 뺀 성과(+$43.0k)를 함께 봅니다. 매일 매수 대비 규칙의 우위(+$105.5k)는 이날 포함 여부와 관계없습니다.

**요일별** — 수요일이 약합니다(FOMC·CPI가 수요일에 몰림, 이벤트 없는 수요일도 오후까지 상승이 이어진 비율 50% vs 다른 요일 60~63%). 아직 통계적으로 확정되지 않아 규칙은 그대로 두고 가설로만 기록합니다.

## 한계

- 4.3년 약 400건, 이익이 소수의 큰 날에 몰려 있습니다(요일마다 상위 3건, 전체의 4%를 빼면 적자). 거래당 표준편차 약 $2,600이라 우위를 통계적으로 확정하려면 수년이 필요합니다.
- 규칙은 약 1,600개 조합을 시험하며 골랐습니다. 실제 기대치는 백테스트보다 낮게 봐야 합니다.
- 거래 순서를 바꿔 5,000회 재표본하면 최대낙폭 중앙값은 −$25.6k로 실제(−$19.7k)보다 큽니다.
- 2026-09-24부터 매일 새 데이터로 판단과 손익을 기록하고 있습니다(`scripts/40_forward_log.py`).

## 방법

- **SPX 가격**: 옵션 풋콜 패리티 $F = K + C - P$ (|C−P|가 가장 작은 행사가 5개의 중앙값). 0DTE라 할인·배당 효과는 0.2pt 이하로 무시. 실제 지수와 분 단위 차이 중앙값 0.35pt.
- **체결**: 매수 = 5·10초 뒤 매도호가, 손절 = 그 분 매수호가, 만기 = 16:00 SPX 종가 현금정산.
- **시점**: 판단 재료(SPX 10:00:00, MNQ 09:55 5분봉)는 모두 10:00:00까지 확정된 값만 사용.

## 실행

```bash
pip install -r requirements.txt
setx DATABENTO_API_KEY "db-..."        # Windows, 새 터미널에서 적용
python scripts/02_download_0dte.py     # 비용 조회만 (--go 로 실제 다운로드)
```

데이터 폴더는 환경변수 `SPX0DTE_DATA`(기본 `./data`)로 지정합니다.
**Databento 원본 데이터와 그로부터 만든 중간 파일은 라이선스상 저장소에 포함하지 않습니다.** 유료 다운로드 전에는 항상 비용을 먼저 조회합니다.
